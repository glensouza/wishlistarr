# Discovery lists

Parents can add up to five Trakt or MDBList lists in discovery list settings. Enter the numeric list ID, a shelf name and the provider's key (a Trakt client ID or MDBList API key). Select MDBList external for an imported external list, including a Letterboxd list. Keys are encrypted at rest and are never returned by the settings API. Leave a key blank to keep its existing value. A list appears on each kid home after it has refreshed; empty shelves are omitted.

The `discovery-lists` job refreshes every six hours by default and is also started after settings are saved. The first 100 source items are read, and up to eight movie or show TMDB IDs are retained per list. Unsupported item types and entries without a TMDB ID are skipped. A failed refresh retains the previous snapshot, including after a rename; a successful empty list replaces it. A rate-limited provider is skipped until its `Retry-After` time, or for five minutes when the header is absent. This cooldown is kept in memory and resets on restart. Only IDs are stored, not TMDB details. Home fetches TMDB details and applies the same profile policy as the other home shelves before displaying any item. Titles whose details or policy checks fail are omitted.

Trakt's [list API](https://trakt.docs.apiary.io/reference/movies) requires the client ID and API version headers and only returns public lists for the numeric list endpoint. MDBList's [API schema](https://api.mdblist.com/schema/) describes list IDs, the API key parameter and separate movie and show buckets. MDBList [supports external lists](https://docs.mdblist.com/docs/external_lists), including Letterboxd imports. Provider calls use fixed HTTPS hosts and do not follow redirects or log request URLs.
