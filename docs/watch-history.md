# Watch history

Watch history is optional. To enable it, configure `Tautulli__Url` as the full base URL (including any HTTP root) and `Tautulli__ApiKey` as the API key in the app's environment, then restart Wishlistarr. Tautulli 2.18.0 or newer is required for the `X-Api-Key` header. The key is never sent in a URL, and redirects are not followed. Use a trusted connection to Tautulli. Map each profile to a Plex user in the profile settings and select the same Plex server in Wishlistarr and Tautulli. The library index must have completed a full refresh for that server. If a mapping, connection, matching server or index is missing, watch history is unavailable and home continues without the recommendation row.

`GET /api/v1/kid-profiles/{id}/watch-history` is parent-only and returns `{ available, titles }` with private, no-store caching. Each observed title has `kind`, `tmdbId`, `finished`, `percentComplete` and `lastPlayed` (Unix seconds). A missing title means unknown, not unwatched. An observed partial play has `finished: false`; this is not a statement that the title was never completed outside the returned history. Progress is the most recent observed play; a completed play in the window makes `finished` true. For shows, each episode is resolved to its show, so `finished` means at least one episode was completed, not the entire series. Removed or unmatched library items are omitted. Each movie must match its recorded GUID, current Plex metadata and indexed GUID. Each episode must also match its recorded GUID and current show parent, and the current show GUID must match the index. Missing or changed identities are omitted, including after server migrations.

The provider reads at most the 1,000 most recent Tautulli history events for the mapped user, without live sessions. It checks at most 32 distinct recorded identities against Plex, with a ten-second overall verification limit; remaining entries are unknown. Tautulli only knows history collected since it was installed or imported. It may have gaps, deleted history, or older entries beyond this limit. Absent records and unavailable history must not be used as proof that a title is unwatched. Completion uses Tautulli's `watched_status` and its configured thresholds, not a guessed percentage. No history is persisted by Wishlistarr.

When home has at least one configured row, it may add a "Because you watched" row based on a recently observed finished title. Recommendations use TMDB's movie or TV recommendation endpoint and pass through the same content policy as other home rows. A partial play alone never supplies the seed. If history or recommendations cannot be read, the row is omitted. History gathering has its own three-second budget.

See [Tautulli's API reference](https://github.com/Tautulli/Tautulli/wiki/Tautulli-API-Reference) for the history and server information responses and [Tautulli's FAQ](https://github.com/Tautulli/Tautulli/wiki/Frequently-Asked-Questions) for its history limitations.
